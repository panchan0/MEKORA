# Recursos de MEKORA

Coloca aquí archivos estáticos que deban conservar su nombre durante el build:

- `audio/`: música, ambiente y efectos de sonido.
- `icons/`: iconos SVG o rasterizados.
- `images/`: fondos, ilustraciones y arte de interfaz.
- `textures/`: niebla, terreno, partículas y materiales.

En JavaScript y CSS se accede a esta carpeta desde `./assets/...` después del build.
